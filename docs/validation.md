数值演示仍只证明自动化和持久化闭环，不能据此作化学归属结论。

## 边界

- 数值优化成功或收敛不等于化学模型正确。
- 完整 VGP 模型写入要求原始强度和校准未变；能量校准由独立 VGD 流程交付。
- 文件未持久化的 `area_ratio` / `height_ratio` 显示比例，重读可能为 1；其它参数和约束仍严格核对。原子质量未持久化时报告未知。
- 接口限于 README 列出的精确原生构建、一维等间隔谱图和公共背景。布局相关文件有 SHA-256 校验。
- apply 保存检查点和结果，并让 Avantage 加载完整项目副本；另存也改变当前文档路径。源文件不覆盖。写操作响应丢失后先核对结果，不自动重试。

复现：普通测试 `python -m pytest -q`；安装本机 Avantage 后设置 `AVANTAGE_INTEGRATION=1` 和 `AVANTAGE_VGP_FIXTURE`。实时测试另需运行一个 Avantage，并显式设置 `AVANTAGE_LIVE_INTEGRATION=1`；它会打开自己复制的项目。样例原生三峰流程见 `examples/native_fit_workflow.py`，不包含化学归属结论。
