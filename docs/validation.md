# 本机验证记录

2026-10-13 至 2026-10-14，在 Windows x64 和 Avantage 6.9.0.59 上验证并再次复测：**38 项测试通过，0 失败**。官方 MCP 客户端发现 31 个工具，并完成真实原生分峰和结果重载。

覆盖以下流程：

- 源文件保护、中文路径、VGD 保存重开和能量校准。
- Linear、Shirley、Smart、Tougaard、Simple 五类原生背景。
- 对称和非对称连续拟合、同一模型再次拟合。
- 固定参数、范围和峰位关联约束；全部固定时返回明确错误并保留模型。
- Product、Sum、Convolution 原生 G/L 组合。
- 迭代上限、限定背景范围及 RSS/RMSE 的有效区域。
- 原生 VGT 保存、独立加载核对、导入后再次拟合。
- JSON 模型恢复及关联峰编号重映射。
- 桥接进程超时、协议错误、关闭和会话失效处理。
