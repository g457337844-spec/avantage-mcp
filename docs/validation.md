# 验证状态

2026-10-19，Windows x64，Avantage 6.9.0.59，MCP 1.3.0。

## 原窗口修改与保存

本机使用两份隔离项目验证，不修改用户原文件。已有峰参数、现有约束、原生拟合、默认完整备份与原窗口普通保存均通过实际 stdio MCP 流程。保存后核对所有谱区的原始数据、能量轴、模型和网格关联，并用独立工作进程逐点重读曲线。修改一个项目时另一份文件保持不变，未新增结果窗口。

原生拟合闭环检查了独立优化子进程、收敛报告、残差、实时保存以及过期会话拒绝。改变峰数量等不支持的结构修改在实际应用前拒绝。未修改的文档可直接核验磁盘内容，不发送多余保存命令。

持久连接每个应用生命周期只激活一次厂商接口。空白应用的 10 次独立重连，以及加载两个项目后的 15 次重连，主窗口引用计数均保持稳定。应用正常退出后旧辅助进程退出；正常启动新应用并重新打开已保存项目后，原始数据和总模型与磁盘逐点一致。重启后再次完成原窗口两轮保存与未修改保存测试。

此前曾出现延迟崩溃，因此没有把短时保存成功当作发布依据。本版改用持久 STA 连接与运行对象表，修复辅助进程继承通信管道导致客户端退出卡住的问题，并加入启动/模态窗口检查、应用身份检查和跨 MCP 进程互斥。新实现的持续测试及正常重启检查中未出现新的崩溃记录。该结论限于列明的版本和测试范围，不代表任意厂商版本均兼容。

## 文件流程与限制

私有 VGD/VGP 读取、原生背景与峰形、参数和约束、独立原生优化、模型导入导出和完整 VGP + DATA 保存已有本机验证。文件替换要求目标文档关闭；已有峰参数调整使用实时流程即可保留原窗口。实时修改不支持改变峰数量、背景或约束属性集合，也不支持自动打开/关闭文档。失败或响应丢失时保留备份并停止，不自动重试写入。

数值收敛不等于化学归属正确。外部优化、参数导入与厂商原生优化应分别报告，不得混称。接口按精确厂商二进制校验值启用；不提供硬件采集、多维分峰或 RSF 定量。

## 复现

普通测试：`python -m pytest -q`。可选厂商测试需要 `AVANTAGE_INTEGRATION=1` 和匹配 DATA 目录的 `AVANTAGE_VGP_FIXTURE`，先复制输入。实时禁用保护测试另需 `AVANTAGE_LIVE_INTEGRATION=1`，不会自动打开或关闭文档。

实时写入回归另需 `AVANTAGE_LIVE_WRITE_TEST=1`、`AVANTAGE_LIVE_WRITE_FIXTURE`，明确指定已经打开的可丢弃测试副本。必须在其旁边放置同名 `.mcp-test.json`，内容为 `{"purpose":"disposable-live-test","path":"测试副本的绝对 Windows 路径"}`（JSON 路径反斜杠需转义）。测试两次修改并恢复已有峰标签，核对完整备份和同一窗口，再验证未修改保存。不得用用户原件作为测试输入。不同写入测试必须串行；同时复制正在保存的 DATA 目录不是有效测试输入。

Windows 进程管道测试不启动 Avantage、不调用厂商 COM；它验证辅助进程仍运行时，工作进程的通信管道已正常关闭。跨进程互斥测试验证嵌套事务可重入、另一个 MCP 进程被拒绝，以及退出后锁释放。

最终普通测试 111 项通过、37 项跳过；另行显式运行的两项实时禁用保护测试和一项原窗口保存回归通过，发布路径的实际 stdio MCP 连续两轮修改/保存和独立重读也通过。跳过的测试不算通过。仓库只发布源码、安装入口、说明和测试，不发布用户谱图、化学结果、备份、厂商 DLL、许可证或本机配置。
