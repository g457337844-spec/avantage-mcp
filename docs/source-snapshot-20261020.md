# 2026-10-20 源码快照与验证范围

这是当前本机源码的同步，不是新的功能发布。生产版本保持 1.4.0，安装和正常桥接入口保持原有行为。

## 已有生产能力

读取 VGD/VGP、原生背景和峰形、峰参数与约束、隔离原生优化、完整项目保存，以及已打开窗口中已有峰参数与已有约束属性的修改和普通保存。实时操作仍受精确厂商版本、应用状态、数据指纹、回读与备份保护。

窗口刷新可能重新计算派生面积。当前自动同步只适用于已有范围约束、差异不超过 0.005% 等严格条件；其他差异仍会回滚并生成诊断。不得忽略验证失败、扩大阈值或将传输成功视为科学拟合正确。

## 未发布的研究代码

`native/inprocess/` 由独立研究构建脚本按需编译，不属于正常 `native/*.cs` 桥接构建。正常安装不会注册这些研究 COM 类。

已在一个可丢弃测试副本的同一窗口内验证：宿主 UI 线程回调与原生文档身份；已有模型 6→7→6 的增删峰及普通保存、独立磁盘回读；空谱区创建一个主峰条目和拟合峰再删除恢复；进程内模型与原始数据指纹和外部读取一致。测试期间其他已打开文档的身份、路径与修改状态保持一致。这不等于对那些文档的全部原始数据做过逐点比较。

通用模型计划校验、原生对象辅助代码、两阶段事务与回滚写入插件已有源码，但通用写入插件尚未完成真实端到端激活、故障恢复和生产集成验证。需要继续完成版本化程序集、安装和注册生命周期、正式工具接入及实时回归；不能用于宣称已支持任意实时新增/删除分峰、换背景或增删约束属性。

研究笔记记录接口推导和历史尝试；历史初始设计与当前源码不同处，以本文件、当前源码及较新的实测记录为准。不能复用已加载程序集的名称/CLSID去覆盖代码，也不能把远程 COM 代理指针当成本进程 C++ 文档地址。
