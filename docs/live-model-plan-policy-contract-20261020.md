Top-level required keys:

- version: integer1
- request_id: exactly32 hex characters, identifying this bounded request.
- document_path: nonempty string <=32767 UTF16 chars, fully qualified Windows drive or UNC file path, extension .vgp (case insensitive). No URL/NUL. Shape validation only, no file existence/read.
- spectrum_index: integer0..4095
- expected_raw_sha256: exactly64 hex chars
- expected_peaks, desired_peaks: arrays0..100 of full native peak snapshots. These are transported as JSON, no raw intensity arrays. Expected background may be null for incomplete original models; each desired peak requires an explicit valid background. All desired backgrounds must be equal in operational fields (type/bounds/mode/average/step/extensions); properties description is diagnostic, ignore it for equality.
- source_peak_indices: one entry per desired peak. Existing source indices must refer to expected_peaks and be strictly increasing; newly created peaks use null and form a suffix. Reordering or duplicating existing objects is rejected before mutation.
